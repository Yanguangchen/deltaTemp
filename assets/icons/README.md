# DeltaTemp app icon

The shared app icon is a frosted-glass delta on a sage background, matching the app's green palette. Generated with the built-in image generation tool, then resized without changing the artwork.

- `deltatemp-1024.png`: opaque 1024 px master.
- `../../apple-touch-icon.png`: opaque 180 px Apple home-screen icon. The platform applies its own corner mask.
- `../../favicon-16x16.png` and `../../favicon-32x32.png`: browser tab icons.
- `../../favicon.ico`: multi-resolution 16, 32 and 48 px fallback.

The HTML entry points reference these assets with relative paths so they work when opened locally or hosted under a subdirectory. Keep the root icon files alongside `index.html` when copying the application.

## Generation prompt

Use case: logo-brand. Asset type: production app icon for DeltaTemp, a temperature data and radar annotation web app. Create one minimalistic glassmorphic app icon, square 1024x1024. Full-bleed opaque soft sage green background with a restrained smooth tonal gradient. Center one large, bold, softly rounded triangular delta outline, formed from thick translucent frosted glass, with an open triangular center. The delta should occupy roughly 68 percent of the canvas width, clearly recognizable at small favicon sizes. Beautiful subtle glass refraction, polished translucent edges, soft white upper-left highlights, deep forest-green shading giving crisp silhouette contrast. Straight-on orthographic view, balanced symmetrical composition, restrained depth and a very soft close shadow. Simple premium utility-app design. No letters, words, thermometer, extra symbols, decorative particles, mockup, border, or surrounding scene. Do not round the outer square corners; the operating system will mask the icon. Output only the finished square icon.
